# Update GitHub Profile & Repo — Browser Automation Prompt

> **Purpose:** Update GitHub profile and repo to point to the live paulprae.com site.
> **Tool:** Send this prompt to Claude in Chrome (browser automation).

---

## Prompt

```
I need to update my GitHub profile and repository to link to my live website. Please do the following:

### 1. Update GitHub Profile Website

1. Go to https://github.com/settings/profile
2. Find the "Website" or "Blog" field
3. Clear any existing value and enter: https://paulprae.com
4. Scroll down and click "Update profile" to save
5. Take a screenshot to confirm

### 2. Update Repository Description & URL

1. Go to https://github.com/praeducer/paulprae-com
2. Click the gear icon (⚙️) next to "About" in the right sidebar
3. Update the "Description" to: AI-powered career platform — paulprae.com
4. Update the "Website" URL to: https://paulprae.com
5. Make sure "Releases", "Packages", and "Deployments" checkboxes are appropriate
6. Click "Save changes"
7. Take a screenshot to confirm

### 3. Verify

1. Go to https://github.com/praeducer and confirm the website link shows paulprae.com
2. Go to https://github.com/praeducer/paulprae-com and confirm the About section shows the URL
3. Take final screenshot

Expected: Both the profile and repo link to https://paulprae.com.
```
